## 系統定位

這不是 ERP，也不處理 BOM。

業務下單後會提供一份「需求單」給現場助理；助理把需求單資料手動輸入這個小工具，再根據現場實際完成噴漆的機台進行配單。

本系統只用來輔助現場掌握：

1. 有哪些機台已完成組裝、等待噴漆。
2. 哪些機台已噴漆入庫、可以配給需求單。
3. 哪些機台已配單、接下來要去校機。

## 確認過的實際流程

```text
業務下單
→ 業務提供需求單給現場助理
→ 助理建立需求單
→ 機台組裝完成
→ 噴漆完成後登記入庫
→ 助理依需求單將機台配單
→ 機台移至待校機區
```

## 畫面架構（已完成第一版）

首頁有兩個入口：

- 組裝系統
- 配單系統

進入「配單系統」後，有三個按鈕：

| 按鈕 | 用途 |
| --- | --- |
| 新訂單建立 | 助理輸入業務提供的需求單號、機型、需求數量 |
| 入庫機台配單 | 處理噴漆入庫與可用機台的配單 |
| 已完成配單 | 查看已配好的機台，必要時取消配單 |

## 機台會出現在哪裡

| 狀態 | 顯示位置 | 可操作內容 |
| --- | --- | --- |
| 組裝完成、尚未噴漆入庫 | 入庫機台配單 → 待噴漆入庫 | 填寫噴漆完成日期、按入庫 |
| 已噴漆入庫、尚未配單 | 入庫機台配單 → 已入庫待配單 | 選擇需求單並確認配單 |
| 已配單、等待校機 | 已完成配單 | 查看需求單號；需要時取消配單 |

## 已確認的操作規則

- 組裝完成時間只顯示「年月日」。
- 已配單時，畫面主要顯示「需求單號」，不要顯示太多狀態文字。
- 一台機台一次只能配給一張需求單。
- 同一需求單的同一機型，配單數量不能超過需求數量。
- 機台若要改配別張需求單：先取消配單，再重新配單；不做「改配」功能。
- 取消配單時必須有確認提示。
- 噴漆入庫後保留原本頁面捲動位置，避免跳回最上方。
