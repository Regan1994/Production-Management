# 生管流程更新：需求單、噴漆入庫與配單

更新日期：2026-11-19（Asia/Taipei）

## 已確認流程

~~~text
業務下單
→ 業務提供需求單給現場助理
→ 助理將需求單輸入生管小工具
→ 機台完成噴漆並登記入庫
→ 助理依需求單確認並配給對應機台
→ 校機
~~~

## 小工具範圍

- 不建立或管理 ERP 正式訂單。
- 不讀取、不計算、不維護 BOM。
- 需求單由現場助理依業務提供的紙本／既有資料手動輸入。
- 需求單記錄需求單號、機型與需求台數，供查詢已配、尚缺與對應製號。

## 機台狀態與規則

| 狀態 | 條件 | 可進行動作 |
| --- | --- | --- |
| 待噴漆 | 組裝 FINISH，尚未登記噴漆完成 | 登記噴漆完成入庫 |
| 已噴漆可用庫存 | 已登記噴漆完成，尚未配單 | 依需求單確認配單 |
| 已配單／待校機 | 已噴漆且已配給需求單 | 取消配單、改配、交校機 |

1. 只有「已噴漆可用庫存」的機台可以配單。
2. 同一製號同一時間只能有一筆有效配單。
3. 同一張需求單的同一機型不可超過需求台數。
4. 取消配單後，機台回到「已噴漆可用庫存」；保留取消人、時間與原因。
5. 不記錄儲位或實體位置。
