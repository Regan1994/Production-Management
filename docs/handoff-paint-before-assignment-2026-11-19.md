# 生管系統交接｜噴漆完成後入庫與配單

更新日期：2026-11-19（Asia/Taipei）  
狀態：流程已確認，尚未依本文件改造程式

## 1. 已確認的正確流程

組立報工與工時紀錄在組裝 FINISH 時就結束；此時機台尚未是生管可配單庫存。

```text
組裝 START／FINISH
→ 記錄組裝工時與製號
→ 待外包噴漆
→ 業助確認噴漆完成日
→ 進入可用庫存
→ 配給訂單
→ 交校機
```

噴漆為外包作業。業助需要在機台回廠後，依實際完成情況手動確認哪些製號已噴漆，並保存完成日期與該次完成的機台數量。

## 2. 庫存定義

可用庫存不是「已組裝完成」的機台，而是同時符合以下條件的製號：

1. 組裝 FINISH；五軸仍須旋、傾、尾、組四段皆完成。
2. 已登記噴漆完成日。
3. 尚未配給訂單。

因此統計至少要區分：

- 待噴漆：已組裝完成、尚未登記噴漆完成。
- 可用庫存：已噴漆、尚未配單。
- 已配單：已噴漆、已配給訂單，等待交校機。

每個數量都必須可展開或追溯至實際製號。

## 3. 噴漆完成登記

不使用逐台必須重複輸入日期的方式。噴漆頁面應提供：

```text
篩選機型
→ 顯示待噴漆製號
→ 勾選本次完成的多台機台
→ 填寫一個噴漆完成日
→ 確認
```

系統要自動：

- 對每個勾選製號保存相同的噴漆完成日。
- 顯示本次登記完成台數。
- 將機台從待噴漆移入可用庫存。
- 保存操作人、時間與製號清單的稽核紀錄。

## 4. 配單方式

配單只可使用已噴漆且未配單的可用庫存。

```text
輸入或選擇單號
→ 選擇機型
→ 勾選該機型的可用庫存製號，可一次多台
→ 完成配單
```

同一張單可重複新增不同機型的配單；同一機型也可一次選多個製號。訂單的實際配單數量由勾選的製號數量自動計算，不能只手動加減數字。

未來若需要在尚未有庫存時預先記錄客戶需求，訂單可保留「機型＋需求台數」明細；但配單完成數仍必須以實際製號為準。

## 5. 與目前實作的差異

目前程式已具備完成機台、訂單、多機型需求、配單歷程與噴漆日期欄位，但順序仍是舊規則：

```text
組裝完成 → 配單 → 噴漆完成
```

目前限制「噴漆完成前必須先配單」以及「已噴漆不可配單」均不符合新流程，需移除或反轉。

組裝條碼的 START／FINISH 掃描與工時紀錄目前正常，這次改造不得影響掃描流程。

## 6. 下次實作順序

1. 將完成機台的初始生管狀態改為待噴漆，不列入可用庫存。
2. 建立待噴漆清單與多台勾選的噴漆完成登記。
3. 將可用庫存改為已噴漆、未配單製號。
4. 將配單入口移至已噴漆可用庫存，支援單號、機型與多製號勾選。
5. 調整統計為待噴漆、可用庫存、已配單待交校機。
6. 更新配單／噴漆稽核紀錄與測試案例。

3. 訂單是否要在實際配單前先建立需求台數，作為未來排產與補庫存的依據。
